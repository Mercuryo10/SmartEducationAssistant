# 工具服务层设计（MCP 工具服务层落地）

> 配套文档：`00-项目总览.md`（技术基线）· `02-系统架构设计.md`（工具层职责）· `05-Agent编排设计.md`（图调用方）。
> 代码位置：`app/tools/`（工具函数）+ `app/services/`（业务服务封装，供工具调用）。

## 1. 设计目标

1. **可复用**：OCR / 语音 / 检索等被多个 Agent 共用的能力抽成独立工具，避免重复实现。
2. **可插拔**：工具对外暴露**签名 + JSON Schema**，LangGraph 自动识别；替换实现（如换 OCR 引擎）不影响调用方。
3. **可扩展**：本层对应原始方案「MCP 工具服务层」，可整体封装为标准 **MCP Server**（§6）。

## 2. 工具清单总览

| 工具 | 文件 | 功能 | 被谁使用 |
|------|------|------|----------|
| `ocr_extract` | `ocr_tool.py` | 图片 OCR 提取文字（PaddleOCR） | qa / grading / mistake |
| `speech_to_text` | `asr_tool.py` | 语音转文字（faster-whisper small） | qa |
| `retrieve_knowledge` | `retrieval_tool.py` | 知识库向量检索（FAISS，top_k=5） | qa |
| `grade_objective` | `grading_tool.py` | 客观题答案比对判分 | grading |
| `generate_exercise` | `exercise_tool.py` | 按模板生成可解题目 | exercise |
| `schedule_push` | `push_tool.py` | 推送触达（渠道分发，mock/可扩展） | push |
| `classify_knowledge_point` | `knowledge_tool.py` | 文本 → 知识点分类 | mistake |

## 3. 工具定义规范

- 统一用 LangChain `@tool` 装饰器；**docstring 写功能说明与参数语义**（LangGraph 据此生成 JSON Schema）。
- 参数/返回值**用类型注解**（`str` / `int` / `list[str]` / `dict`）。
- 每个工具文件顶层提供 `register_tools() -> list[BaseTool]`，供 Agent 绑定。

```python
# app/tools/retrieval_tool.py（示例）
from langchain_core.tools import tool
from app.services import rag_service

@tool
def retrieve_knowledge(query: str, top_k: int = 5) -> list[dict]:
    """从知识库检索与问题最相关的片段，用于 RAG 回答。
    返回列表，每项含 text/source/doc_id/chunk_index。
    """
    return rag_service.retrieve(query, top_k=top_k)

def register_tools() -> list:
    return [retrieve_knowledge]
```

## 4. 各工具实现要点

### 4.1 `ocr_extract(image_path) -> str`

- 后端：PaddleOCR（CPU），**进程级单例 + 惰性加载**：

```python
# app/services/ocr_service.py
_ocr = None
def get_ocr():
    global _ocr
    if _ocr is None:
        from paddleocr import PaddleOCR
        _ocr = PaddleOCR(use_angle_cls=True, lang="ch", show_log=False)
    return _ocr

def extract_text(image_path: str) -> str:
    res = get_ocr().ocr(image_path, cls=True)
    lines = [line[1][0] for block in res for line in (block or [])]
    return "\n".join(lines)
```

- 错误处理：文件不存在 / 无法识别时抛 `ToolExecutionError`（见 `app/core/exceptions.py`），由调用方转为结构化错误。
- 缓存：`cache.py` 以 `file_hash → text` 缓存 1 小时，重复图片免重算。

### 4.2 `speech_to_text(audio_path) -> str`

- 后端：`faster-whisper` `small` 模型，`compute_type="int8"`，`device="cpu"`，同样惰性加载单例。
- 语言：中文优先，`language="zh"`（可空）。
- 输出：转写文本（去掉标点前后多余空白）。

```python
# app/services/asr_service.py（要点）
from faster_whisper import WhisperModel
_model = None
def get_model():
    global _model
    if _model is None:
        _model = WhisperModel("small", device="cpu", compute_type="int8")
    return _model

def transcribe(path: str) -> str:
    segments, _ = get_model().transcribe(path, language="zh")
    return "".join(s.text for s in segments).strip()
```

### 4.3 `retrieve_knowledge(query, top_k=5) -> list[dict]`

- 流程：`embedding_client.embed_query(query)`（1024 维）→ 归一化 → `vector_store.search(vec, top_k)` → 拼装元数据（`text/source/doc_id/title`）。
- 依赖 `app/storage/vector_store.py` 的 `VectorStore` 接口（详见 `03-数据库设计.md` §4）。

### 4.4 `grade_objective(student_answer, reference_answer) -> dict`

- 纯规则实现（不调用 LLM）：
  1. 选择题：去空格/统一小写后相等即对。
  2. 判断题：`对/错/√/×/T/F` 归一化后比较。
  3. 填空题：去除空白与全半角差异后比较；支持「多空答案」按 `|` 或 `；` 分隔逐空比对。
- 返回 `{"is_correct": bool, "score": 0|100, "comment": "..."}`。

### 4.5 `generate_exercise(template, params_schema, difficulty) -> dict`

- 读 `exercises` 模板 + `params_schema` → 程序化生成参数（用 `random` + `secrets`）→ **答案自洽校验**（代入验算）→ 可选 LLM 润色。
- 返回 `{"question_text", "answer", "explanation"}`。
- 详见 `05-Agent编排设计.md` §5.4。

### 4.6 `schedule_push(task: dict, channel: str) -> bool`

- 渠道分发接口：`channels = {"mock": MockChannel, "wechat": ..., "email": ..., "sms": ...}`。
- **演示默认 `mock`**：把触达内容写入 `push_logs.detail`（控制台打印日志）。
- 新增渠道：实现 `push_tool.py` 中的 `Channel.send(content) -> bool` 接口即可，业务零改动。

### 4.7 `classify_knowledge_point(text) -> dict`

- 调用当前 LLM（`get_chat_llm()`）：在 `knowledge_points` 名称列表中匹配最相关知识点。
- 返回 `{"knowledge_point_id", "knowledge_point_name", "confidence"}`。

## 5. 业务服务层（`app/services/`）

工具与 Agent 依赖的底层服务，**独立于 LangGraph**：

| 文件 | 职责 |
|------|------|
| `llm.py` | LLM/Embedding 客户端工厂：`get_chat_llm()` / `get_embedding_client()` / `generate()` |
| `rag_service.py` | 知识库增删、检索、溯源组装（供 `retrieve_knowledge` 与 qa_agent 使用） |
| `ocr_service.py` | PaddleOCR 封装（惰性单例） |
| `asr_service.py` | faster-whisper 封装（惰性单例） |
| `scheduler.py` | APScheduler 定时扫描到期推送任务 |

```python
# app/services/llm.py（要点）—— 提供商工厂：开发 DeepSeek/千问，生产本地 Ollama
from langchain_openai import ChatOpenAI, OpenAIEmbeddings
from app.core.config import settings

def get_chat_llm(**kwargs) -> ChatOpenAI:
    if settings.LLM_PROVIDER == "local":            # 生产：本地 Qwen（Ollama OpenAI 兼容）
        return ChatOpenAI(
            model=settings.LOCAL_LLM_MODEL,          # qwen2.5:14b
            api_key="ollama",                        # 本地端点用占位 key
            base_url=settings.LOCAL_LLM_BASE_URL,    # http://localhost:11434/v1
            streaming=True, **kwargs,
        )
    # 开发：DeepSeek 云 API
    return ChatOpenAI(
        model=settings.DEEPSEEK_MODEL,               # deepseek-v4-flash
        api_key=settings.DEEPSEEK_API_KEY,
        base_url=settings.DEEPSEEK_BASE_URL,         # https://api.deepseek.com/v1
        streaming=True, **kwargs,
    )

def get_embedding_client() -> OpenAIEmbeddings:
    if settings.EMBEDDING_PROVIDER == "local":       # 生产：本地 bge-m3（Ollama）
        return OpenAIEmbeddings(
            model=settings.LOCAL_EMBEDDING_MODEL,    # bge-m3（1024 维）
            api_key="ollama",
            base_url=settings.LOCAL_EMBEDDING_BASE_URL,
        )
    # 开发：千问云 API
    return OpenAIEmbeddings(
        model=settings.QWEN_EMBEDDING_MODEL,         # text-embedding-v4（1024 维）
        api_key=settings.QWEN_API_KEY,
        base_url=settings.QWEN_BASE_URL,
    )
```

## 6. 可选：封装为标准 MCP Server

若想在简历/答辩中强调 **MCP（Model Context Protocol）** 能力，可把工具层封装为 MCP Server（**不影响既有功能**，作为可选扩展）：

```python
# app/mcp_server.py（可选扩展，示例）
from mcp.server.fastmcp import FastMCP
from app.tools import ocr_tool, asr_tool, retrieval_tool

mcp = FastMCP("EduMentor Tools")

@mcp.tool()
def ocr_extract(image_path: str) -> str:
    """图片 OCR 提取文字。"""
    return ocr_tool.ocr_extract(image_path)

@mcp.tool()
def retrieve_knowledge(query: str, top_k: int = 5) -> list[dict]:
    """知识库向量检索。"""
    return retrieval_tool.retrieve_knowledge(query, top_k)

if __name__ == "__main__":
    mcp.run()          # stdio 模式
```

> 说明：本项目核心编排仍使用 LangGraph 直接绑定工具函数；MCP 封装用于展示「工具服务标准化」的能力，便于面试讲解与未来接入通用 Agent 客户端。

## 7. 错误处理约定

- 统一异常基类 `EduMentorError`（`app/core/exceptions.py`），工具层抛 `ToolExecutionError` / `ModelCallError`。
- 工具内部**不捕获**业务异常向上抛，由编排层 catch 并转结构化错误（`04-API接口设计.md` §8）。
- 本地模型（OCR/ASR）初始化失败应有明确日志与降级提示（如「OCR 模型未就绪」），不导致进程崩溃。
