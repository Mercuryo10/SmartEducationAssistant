# 开发规范与编码约定

> 配套文档：`00-项目总览.md`（目录结构）· `02-系统架构设计.md`（分层依赖）· `06-工具服务层设计.md`（工具约定）。
> 本文件是 **AI coding 编码时的硬性规范**。实现代码必须遵守，否则视为缺陷。

## 1. 语言与注释约定

- 代码标识符（变量/函数/类/文件）一律 **英文**，语义清晰。
- **docstring 与代码内注释使用中文**（面向中文团队与答辩阅读）。
- 所有公开函数必须有 docstring：一句功能说明 + 关键参数/返回值说明（LangGraph 工具类 docstring 会被自动解析为 JSON Schema，务必写清楚）。
- 单文件控制在 **400 行以内**，超出则拆分模块。

## 2. 目录与模块规范

- 目录名、模块名：**全小写蛇形**（`snake_case`），如 `app/services/rag_service.py`。
- 类名：**PascalCase**（如 `RAGService`、`MistakeRepository`）。
- 函数/变量：**snake_case**。
- 常量：全大写 + 下划线（如 `RETRIEVE_TOP_K = 5`）。
- 每个 Python 包必须有 `__init__.py`（可只含文档字符串）。

## 3. 分层依赖（硬约束）

依赖方向必须**自上而下单向**：`api → agents → tools/services → storage`。

| 模块 | 允许 | 禁止 |
|------|------|------|
| `app/api/*` | 调 agents、services、schemas | 直接操作 storage、直接调 tools |
| `app/agents/*` | 调 tools、services、storage(repositories) | 写 HTTP、import api 层 |
| `app/tools/*` | 调 services、storage | 调 api、agents |
| `app/services/*` | 调 storage、core | 调 api、agents |
| `app/storage/*` | 调 core、models | 调上层任何模块 |

> AI coding 检测：任意文件若违反上表 import 关系，必须重构，不得绕过。

**后端直连禁令**：业务代码（api/agents/tools/services）**禁止直接 `import faiss` / `pymilvus` / `redis` / `pymysql`**。向量库、缓存、数据库一律经 `storage` 层暴露的接口（`VectorStore` / `Cache` / Repository）访问，LLM/Embedding 经 `services/llm.py` 工厂访问。后端实现类（`FaissVectorStore` / `MilvusVectorStore` / `MemoryCache` / `RedisCache`）只能出现在 `storage` 层。

## 4. 类型注解

- 所有函数**必须**有类型注解（参数 + 返回值）。工具函数尤其重要（Schema 生成依赖类型）。
- 业务数据结构用 **Pydantic 模型**（`app/schemas/`）或 `TypedDict`（图状态），禁止裸 dict 传递关键参数。
- 示例：

```python
def grade_objective(student_answer: str, reference_answer: str) -> dict:
    ...
```

## 5. 配置管理

- 一律通过 `app/core/config.py`（`pydantic-settings`）读取 `.env`，**禁止在业务代码里硬编码配置值**。
- 读取方式：`from app.core.config import settings`，如 `settings.DEEPSEEK_API_KEY` / `settings.QWEN_API_KEY`。
- API Key / 密钥只存在于 `.env`，**严禁**写入代码或提交仓库。

```python
# app/core/config.py（要点）—— 双模式配置项与 `00-项目总览.md` §7 保持一致
from pydantic_settings import BaseSettings

class Settings(BaseSettings):
    app_name: str = "EduMentor"
    app_env: str = "dev"                  # dev / prod
    app_port: int = 8000
    upload_dir: str = "data/uploads"

    # LLM 提供商：deepseek(云) | local(Ollama)
    llm_provider: str = "deepseek"
    deepseek_api_key: str = ""
    deepseek_base_url: str = "https://api.deepseek.com/v1"
    deepseek_model: str = "deepseek-v4-flash"
    local_llm_base_url: str = "http://localhost:11434/v1"
    local_llm_model: str = "qwen2.5:14b"

    # Embedding 提供商：qwen(云) | local(Ollama)
    embedding_provider: str = "qwen"
    qwen_api_key: str = ""
    qwen_base_url: str = "https://dashscope.aliyuncs.com/compatible-mode/v1"
    qwen_embedding_model: str = "text-embedding-v4"
    local_embedding_model: str = "bge-m3"

    # 业务库：MySQL（pymysql 驱动）
    database_url: str = "mysql+pymysql://edumentor:edumentor123@127.0.0.1:3306/edumentor?charset=utf8mb4"

    # 向量库后端：faiss(开发) | milvus(生产)

    vector_index_dir: str = "data/vector_index"

    # 缓存后端：memory(开发) | redis(生产)

    model_config = {"env_file": ".env", "env_file_encoding": "utf-8"}

settings = Settings()
```

## 6. 日志

- 统一 `logging`，根 logger 名 `edumentor`；在 `app/core/logging.py` 配置一次格式。
- 关键链路必须打日志：OCR/ASR 耗时、检索 top_k、LLM 调用耗时与 token 数（`usage`）、图路由结果（`task`）、异常堆栈。
- 日志格式（示例）：`2026-08-17 10:00:00 [INFO] [qa_agent] retrieve top_k=5 cost=0.12s`.

```python
# app/core/logging.py（要点）
import logging

def setup_logging(level: str = "INFO") -> None:
    logging.basicConfig(
        level=getattr(logging, level.upper(), logging.INFO),
        format="%(asctime)s [%(levelname)s] [%(name)s] %(message)s",
    )
```

## 7. 异常处理

- 统一异常基类 `EduMentorError(Exception)`；派生：`ToolExecutionError`、`ModelCallError`、`ResourceNotFoundError`、`ValidationError`（`app/core/exceptions.py`）。
- 业务代码**不直接捕获**底层库异常后静默；应捕获 → 记日志 → 转成 `EduMentorError` 子类抛出。
- 路由层注册全局异常处理器：把 `EduMentorError` 转 `{"code","message","detail"}` JSON（见 `04-API接口设计.md` §8）。
- 本地模型（OCR/ASR）初始化失败：记日志 + 抛 `ToolExecutionError`，不得让进程崩溃。

## 8. 异步与线程

- FastAPI 路由用 `async def`；阻塞操作（OCR/ASR/FAISS 检索）用 `def`（FastAPI 自动放线程池）或 `run_in_executor`，**避免阻塞事件循环**。
- LLM 流式用 `async` 生成器 + `await`，逐 token 产出发给 SSE。

## 9. 数据库访问

- 通过 `app/storage/db.py` 的 `get_session()` 上下文管理器获取 session。
- ORM 模型集中在 `app/storage/models.py`；字段命名与 `03-数据库设计.md` 完全一致。
- **禁止**在路由/Agent 层写原生 SQL；一律走 Repository。

## 10. 测试

- 单测放 `app/tests/`，命名 `test_<模块>.py`。
- 最低覆盖：`grade_objective`（各题型边界）、`exercise` 参数生成（可解性）、`retrieve`（命中率）、`supervisor` 路由分类。
- 可运行：`python -m pytest app/tests -v`。
