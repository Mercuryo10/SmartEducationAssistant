# 01 · 项目全貌：这是什么项目

> 目标：对 EduMentor「长什么样」建立整体印象，能说清项目结构里每个文件是干什么的。

---

## 1. 项目一句话

**EduMentor 是一个智能教育助手**：用「大模型 + 多 Agent 协作（LangGraph）+ 教育工具服务」实现 5 大能力，让大学生问大模型/Agent 的问题能被专业地答疑、批改作业、分析错题、出练习题、定时推送复习。

- 开发期：你自己的笔记本（Windows），用**云端 DeepSeek API**。
- 生产期：实验室 Ubuntu（有 RTX 4090），用**本地模型**。
- 亮点：**同一套代码，只改 `.env` 就能切换环境**。

## 2. 五大能力（5 个 Agent）

| Agent | 做什么 | 技术亮点 |
|-------|--------|----------|
| 智能答疑 | 回答问题，带知识库溯源 | RAG 检索 + 多模态输入 |
| 作业批改 | 拍照识别作业，自动判分 | OCR + AI 评分 |
| 错题分析 | 错题关联知识点、薄弱点归纳 | 知识点标签 |
| 练习生成 | 按知识点/难度参数化出题 | 模板 + 难度控制 |
| 学习推送 | 按遗忘曲线定时提醒 | 定时任务 |

> 阶段一只是**骨架**，这些 Agent 还没实现。你现在读到的，是「地基」：能启动的空服务 + 配置 + 数据库 + 各种抽象。

## 3. 技术栈表怎么读

看 `docs/00 §3` 那张表，注意它有**两列**：

```
| 项 | 开发期（笔记本） | 生产期（Ubuntu+4090） |
```

同一个"项"，开发期和生产期用**不同的实现**，通过 `.env` 里的开关切换：

- LLM：`deepseek` ↔ 本地 `qwen2.5:14b`
- 向量库：`faiss` ↔ `milvus`
- 缓存：`memory` ↔ `redis`

**这就是项目最核心的设计思想**：凡是要切换的后端，都抽象成「接口 + 工厂」。你会在 `07` 里细看。

## 4. 目录结构逐层讲解

对照你电脑里的实际目录：

```
SmartEducationAssistant/
├── CLAUDE.md              ← AI 编码主指令（也是给你的"项目说明书"）
├── docs/                  ← 构建蓝图：00~10 号文档，先读这里
├── learn/                 ← 你现在看的这份学习计划
├── app/                   ← ★ 全部代码在这
│   ├── main.py            ← 程序入口：创建 FastAPI 应用
│   ├── core/              ← 配置、日志、异常、安全（最底层，谁都能用）
│   ├── api/               ← 路由层：HTTP 接口（现在只有 health）
│   ├── services/          ← 业务服务：llm / health
│   ├── schemas/           ← Pydantic 模型：接口的"请求/响应契约"
│   ├── storage/           ← 数据层：MySQL、缓存、向量库、仓储
│   │   ├── db.py          ← 数据库连接（engine/session）
│   │   ├── models.py      ← 12 张表的 ORM 模型
│   │   ├── cache.py       ← 缓存接口 + 内存实现 + 工厂
│   │   ├── vector_store.py← 向量库接口 + FAISS 实现 + 工厂
│   │   └── repositories/  ← 仓储层：数据访问的统一入口
│   └── static/            ← 前端页面 index.html
├── scripts/
│   ├── init_db.py         ← 一键建库（建表 + 内置数据）
│   └── (后续会有 build_kb.py)
├── requirements.txt       ← 依赖清单（pip install -r 用）
├── .env.example           ← 配置模板（复制成 .env 填真实值）
├── .env                   ← ★ 你的真实配置（含密钥，绝不入库）
├── .gitignore             ← 声明哪些文件不进 git 仓库
└── docker-compose.prod.yml← 生产中间件一键启动（备用）
```

## 5. 每个文件「管什么」速查表

| 文件 | 一句话职责 | 你要找的关键词 |
|------|-----------|----------------|
| `app/main.py` | 创建应用、挂路由、注册异常处理、托管页面 | `FastAPI()`、`include_router`、`exception_handler` |
| `app/core/config.py` | 全部配置项 + 读取 `.env` | `class Settings`、`settings = Settings()` |
| `app/core/exceptions.py` | 统一异常体系 | `class EduMentorError` |
| `app/core/logging.py` | 日志格式 | `setup_logging`、`get_logger` |
| `app/core/security.py` | 密码哈希 | `hash_password`、`verify_password` |
| `app/api/health.py` | 健康检查接口 | `@router.get("/health")` |
| `app/services/health_service.py` | 健康检查的业务逻辑（探测 DB） | `check_database` |
| `app/services/llm.py` | LLM/Embedding 客户端工厂 | `get_chat_llm`、`get_embedding_client` |
| `app/storage/db.py` | 数据库连接 | `engine`、`SessionLocal`、`Base`、`get_session` |
| `app/storage/models.py` | 12 张表的 ORM 模型 | `__tablename__`、`mapped_column` |
| `app/storage/cache.py` | 缓存抽象 | `class Cache`、`MemoryCache`、`get_cache` |
| `app/storage/vector_store.py` | 向量库抽象 | `class VectorStore`、`FaissVectorStore`、`get_vector_store` |
| `app/storage/repositories/*` | 数据访问 | `class UserRepository` 等 |
| `app/schemas/*` | 请求/响应模型 | `class LoginRequest` 等 |
| `scripts/init_db.py` | 建库脚本 | `create_all` |
