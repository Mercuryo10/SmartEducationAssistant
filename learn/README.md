# 阶段一 · 学习计划（EduMentor 项目骨架）

> 写给第一次独立开发项目的你：这份计划不是让你背诵，而是带你**读懂**刚写好的阶段一代码，并掌握「企业级项目」里那些你没见过的套路（分层、配置、接口抽象、仓储模式……）。
> 配合阅读：`docs/00-项目总览.md`、`docs/08-开发规范与编码约定.md`。先读文档蓝图，再对照代码。

---

## 一、学完阶段一，你该能回答的问题

- 一条 `curl http://localhost:8000/api/v1/health` 从发出到返回 JSON，中间发生了什么？
- 为什么代码要分层？依赖方向为什么必须是 `api → services → storage`？
- 配置为什么集中放在一个 `config.py`？`dev` 和 `prod` 双模式是怎么切换的？
- 为什么数据库访问要绕一层 `Repository`，而不是直接写 SQL？
- 为什么缓存、向量库用「接口 + 工厂」，这为什么是面试加分项？
- 拿到任何一份陌生代码，怎么快速读进去？

## 三、前置要求（没有也可以边学边补）

- **Python 基础**：变量、函数、类、`import`、`if __name__ == "__main__"`、用 pip 装包。
- **一点点 SQL 概念**：知道「表、行、主键、外键」即可，不用会写复杂 SQL。
- **不需要** 会 FastAPI / SQLAlchemy / LangChain —— 计划会带着你读。

## 五、每个模块的通用学法（重要）

1. **先读目标**：这一节要回答什么问题？
2. **打开对应文件**：从「入口」读起，不逐行从头读。
3. **遇到不懂的东西**：用 IDE 跳到它的定义（Ctrl+点击 / F12）。
4. **动手改一行**：改完跑一下，看效果变了没——理解代码最快的方式是改它。
5. **口述自检题**：能讲给别人听，才算真的懂了。

## 六、如果中途卡住

- 卡在一个函数：用 IDE「查找引用」，看谁在用它，反过来理解它该做什么。
- 卡在概念：先跳过，把问题记下来，读完后面对应的模块通常会回答。
- 卡在跑不起来：按 `02` 里的「常见错误排查」逐条对。
- 实在看不懂的地方，问我，但请带着「我已经看到第 X 行 / 报错是 XX」来问。
