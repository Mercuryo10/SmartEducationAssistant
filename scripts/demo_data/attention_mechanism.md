# Transformer 中的注意力机制

## 1. 为什么需要注意力机制

传统的序列模型（如 RNN、LSTM）需要把整句信息压缩进一个固定长度的隐状态，句子越长，早期信息越容易被"遗忘"。注意力机制（Attention）的核心思想是：**在处理某个位置时，模型动态地"关注"输入序列中与之最相关的其他位置**，而不是依赖一个压缩后的固定向量。这让模型能直接建立远距离位置之间的依赖关系，这是 Transformer 能并行处理整句、且在长文本上表现更好的关键原因。

## 2. 自注意力（Self-Attention）与 Q/K/V

Transformer 中使用的是自注意力（Self-Attention），即序列中的每个位置都要与其他所有位置计算关联度。实现上引入三个向量：

- **Q（Query，查询）**：当前位置"想问什么"。
- **K（Key，键）**：每个位置"能提供什么信息"。
- **V（Value，值）**：每个位置"实际的信息内容"。

计算流程分四步：

1. 对每个 token，通过三个可学习矩阵 $W_Q, W_K, W_V$ 分别得到 Q、K、V 向量。
2. 用 Query 与所有位置的 Key 做点积，得到注意力分数（相似度）。
3. 分数除以 $\sqrt{d_k}$（Key 的维度）做缩放，再经过 softmax 归一化成注意力权重。
4. 用权重对所有的 Value 加权求和，得到该位置的输出表示。

公式可写作 $\text{Attention}(Q,K,V)=\text{softmax}(\frac{QK^\top}{\sqrt{d_k}})V$。缩放因子 $\sqrt{d_k}$ 的作用是防止点积值过大导致 softmax 梯度消失。

## 3. 多头注意力（Multi-Head Attention）

"多头"指的是把 Q、K、V 切成多组（如 8 个头），每组独立做一次注意力计算，最后拼接再经线性变换。好处是**每个头能关注不同维度的关系**：有的头关注句法关系，有的头关注指代，有的头关注局部词对。多头让模型"从多个角度同时看句子"，表达能力更强。

## 4. 位置编码（Positional Encoding）

自注意力本身对顺序不敏感（交换两个 token 的结果相同），所以 Transformer 需要把位置信息显式加入输入。位置编码通常用正弦/余弦函数生成（可学习位置编码也常见），加到输入 embedding 上，让模型知道每个词在序列中的位置。

## 5. 小结

- 注意力机制解决长距离依赖与并行计算两个问题。
- 自注意力用 Q/K/V 三个向量计算加权表示，$\text{softmax}(QK^\top/\sqrt{d_k})$ 是其核心公式。
- 多头注意力让模型从多个子空间捕捉不同关系。
- 位置编码补偿了自注意力对顺序不敏感的特性。
- 常见疑问：注意力权重需要归一化（softmax）；Q 与 K 相乘得到的是注意力分数，不是权重，权重还要经过 softmax。
